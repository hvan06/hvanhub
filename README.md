# StudentHub

Project PHP đầu tiên: hiển thị lời chào "Xin chào, + tên của bạn".

## Cấu trúc thư mục

```
studenthub/
├── public/
│   └── index.php
├── assets/
│   └── css/
│       └── style.css
└── README.md
```

## Cách chạy project

1. Cài PHP (kiểm tra bằng `php -v`).
2. Mở terminal tại thư mục `hvanhub`.
3. Chạy server tích hợp của PHP:

   ```
   php -S localhost:8000
   ```

4. Mở trình duyệt và truy cập:

   ```
   http://localhost:8000/public/index.php
   ```

Nếu dùng XAMPP: đặt thư mục `hvanhub` vào `htdocs` rồi truy cập
`http://localhost/hvanhub/public/index.php`.
